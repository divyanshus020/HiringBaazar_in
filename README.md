# Hiring Bazaar - AI-Powered Hiring Solutions

Transform your hiring process with AI-powered candidate screening, agency networks, and campus placements.

## Project info

This project is a modern recruitment platform designed to streamline the hiring process using AI.

## Getting Started

Follow these steps to set up the project locally:

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd HiringBaazar_in

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server
npm run dev
```

The only requirement is having Node.js & npm installed.

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment

You can deploy this project to platforms like Vercel, Netlify, or as a static site.
